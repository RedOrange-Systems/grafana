La plataforma de código abierto para la monitorización y la observabilidad

[![License](https://img.shields.io/github/license/grafana/grafana)](LICENSE)
[![Go Report Card](https://goreportcard.com/badge/github.com/grafana/grafana)](https://goreportcard.com/report/github.com/grafana/grafana)

Grafana te permite consultar, visualizar, generar alertas y comprender tus métricas sin importar dónde estén almacenadas. Crea, explora y comparte paneles de control con tu equipo, y fomenta una cultura basada en datos:

- **Visualizaciones:** Gráficos rápidos y flexibles del lado del cliente con multitud de opciones. Los plugins de paneles ofrecen muchas formas diferentes de visualizar métricas y registros (logs).
- **Paneles dinámicos:** Crea paneles de control dinámicos y reutilizables con variables de plantilla que aparecen como menús desplegables en la parte superior del panel.
- **Explorar métricas:** Explora tus datos mediante consultas ad-hoc y desglose dinámico (drilldown). Divide la vista y compara diferentes rangos de tiempo, consultas y fuentes de datos en paralelo.
- **Explorar registros (logs):** Vive la magia de pasar de métricas a registros conservando los filtros de etiquetas. Busca rápidamente en todos tus registros o transmítelos en vivo.
- **Alertas:** Define visualmente reglas de alerta para tus métricas más importantes. Grafana evaluará continuamente y enviará notificaciones a sistemas como Slack, PagerDuty, VictorOps, OpsGenie.
- **Fuentes de datos mixtas:** ¡Combina diferentes fuentes de datos en el mismo gráfico! Puedes especificar una fuente de datos por consulta. Esto funciona incluso con fuentes de datos personalizadas.
